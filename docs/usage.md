# 怎么用

1. 用这个模板建一个 wiki 站点，并准备一个知识库。网址或文件导入会同时建知识库并投影过来。
2. 首页用 welcome（`templates/index.welcome.liquid`）。填写欢迎标题、描述、热搜问题和输入框文案。
3. 知识库里的目录会变成可打开的文档。文章改标题和正文，不要在页面上改 `title` 和 `content`。要让一篇只列出子页，打开 `show_list`。
4. 提问入口是站点首页 `/`。在欢迎区提交问题后进入对话。搜索页只负责带着查询词跳进对话。

没有示例种子，所以快速开始里不会出现「先用示例体验」。编排方案见 [activation.yml](activation.yml)：对话按原目录挂文档、按顶层话题开对话入口，或先把文档铺平再问。
