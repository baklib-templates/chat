# 模板使用说明 — AI Chat

## 1. 模板概览 (Theme Overview)

### 模板名称

**AI Chat 模版**（内部标识：`chat`，版本 **1.2.1**，语法版本 **v2**，范围 **Wiki**）

### 模板描述

适用于智能对话、知识问答和自动回复的 AI 聊天主题。

本主题为 Baklib **Wiki** 对话优先型主题：以 AI 会话为核心入口，首页提供欢迎区、热搜问题与内嵌输入框，用户提问即创建会话并进入对话工作区；左侧栏集成「新建会话」「知识库入口」与「最近对话」列表，支持可选的历史会话删除。对话工作区提供流式回答、引用来源侧栏、Markdown 渲染（含代码高亮与公式）及独立窗口（PiP）模式。同时保留完整文档阅读能力：`page.liquid` 提供左侧目录树、文档搜索弹窗（⌘K）、页内目录、页面工具与反馈，与对话体验在同一站点内无缝切换。顶栏搜索支持文档预览与「向 AI 提问」快捷入口。全局设置涵盖品牌文案、助手名称、AI 回答结束语、布局尺寸、页面反馈与自定义 Head 代码等。

### 适用场景

- **智能客服 / 对话式 FAQ**：以会话为主入口，用户自然语言提问，AI 基于知识库内容回答并展示引用来源
- **企业知识库 AI 助手**：员工或客户通过对话检索内部文档、规范与产品说明，减少翻阅目录成本
- **产品文档 + 对话检索**：在保留传统文档阅读（目录树、页内 TOC、正文页）的同时，提供 AI 问答作为首要交互方式
- **对外知识问答门户**：欢迎首页配置热搜问题引导用户快速上手，适合 SaaS 帮助中心、API 文档站等需要「问即得答」的场景

本主题**不**面向以纯静态文档浏览为主、无需对话入口的站点；若站点以侧栏导航 + 多首页变体为核心体验，应选择 Wiki **Docs** 主题。

### 主要特性

- **欢迎首页**：可配置欢迎标题、描述、热搜问题（每行一条）、输入框占位符与免责声明；点击热搜或提交问题即创建 AI 会话
- **对话工作区**：流式回答、引用来源面板、消息复制、可配置 AI 回答底部提示语；支持独立窗口（PiP）弹出与收回
- **会话侧栏**：新建会话、知识库菜单入口（文案可配置）、最近对话列表；可选开启历史会话删除
- **文档阅读**：`page.liquid` 含左侧目录树、文档搜索弹窗、Turbo 正文区、页内目录、页面工具下拉与页面反馈
- **顶栏搜索**：搜索模态框支持文档预览与向 AI 提问；热搜问题与首页共用配置
- **标签浏览**：`tag.liquid` 按标签分类展示内容，侧栏列出全站标签
- **搜索入口**：`search.liquid` 根据查询词自动创建对话会话
- **七种界面语言**：`zh-CN`、`zh-TW`、`en`、`ko`、`ja`、`de`、`fr`（前台 `*.json` + 编辑器 `*.schema.json`）
- **布局可调**：左侧栏宽度、顶栏高度可在主题设置中调整
- **品牌与合规**：站点副标题、公司名称、机器人名称、备案/版权信息、服务条款与隐私政策链接
- **页面反馈**：Turbo Stream 无刷新提交；反馈辅助提示语支持 JSON 配置
- **现代前端栈**：Tailwind CSS 4、daisyUI、Stimulus、Alpine.js、Turbo；资源由 `src/` 构建至 `assets/`

### 模板类型一览

| 模板文件 | 类型 | 说明 |
| --- | --- | --- |
| `index.welcome.liquid` | 首页 | 欢迎 Hero、热搜问题、对话输入框；提交后跳转对话会话 |
| `page.liquid` | 内容页 | 知识库文档正文；左侧目录树、搜索弹窗、页内目录、页面工具与反馈 |
| `search.liquid` | 搜索 | 根据查询词创建对话会话 |
| `tag.liquid` | 标签页 | 按标签浏览内容，侧栏展示标签列表 |
| `feedback_*_turbo_stream.liquid` | 反馈流 | 页面反馈提交的 Turbo Stream 响应 |

### 全局配置分组（主题设置）

| 分组 | 主要配置项 |
| --- | --- |
| **品牌相关** | 站点副标题、公司名称、机器人名称、AI 回答底部提示语、知识库菜单名称 |
| **AI 相关** | 允许删除对话（开启后用户可在「最近」列表删除历史会话） |
| **布局** | 左侧栏宽度、顶栏高度 |
| **备案信息** | 备案号/版权信息、服务条款链接、隐私政策链接 |
| **页面配置** | 显示发布时间、显示作者、是否启用页面反馈、显示页面工具下拉菜单、页面反馈辅助提示语 |
| **Head 代码** | `<head>` 标签内 HTML 代码（统计、第三方 SDK 等） |

### 首页模板配置要点

| 配置组 / 项 | 说明 |
| --- | --- |
| **欢迎区** | 欢迎标题、欢迎描述 |
| **对话引导** | 热搜问题（每行一个，同步用于搜索弹窗）、热搜区标题、输入框占位符、输入框下方说明（留空则不显示） |

### 内容页模板配置要点

| 配置项 | 说明 |
| --- | --- |
| 是否为栏目页面 | 作为栏目页时展示子页面列表；首页节点始终显示子页面列表 |
| 页面图标 | 建议 1:1，用于子页面列表展示 |
| 页面标题 / 内容 | 知识库同步，只读 |
| 页面描述、页面标签、封面图 | 可编辑，支持检索与展示 |
